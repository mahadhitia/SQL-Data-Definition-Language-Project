## Project Overview

**Mahadhitia Commerce** is a fictional e-commerce company. This project focuses on designing and building a relational database using Microsoft SQL Server to store, organize, and manage data. The database is developed from ground up, starting from creating database, schemas, tables, constraints, and relationships between entities.
